# Demostración de reservas · AW-RiseCR

Demostración interactiva de la web con reservas y del panel en el celular que AW-RiseCR propone a Rigo Tours, Conchal Escape y una casa de masajes.

- Rigo Tours: `?negocio=rigo`
- Conchal Escape: `?negocio=conchal`
- Casa de masajes: `?negocio=masajes`

Precios, horarios, cupos, nombres y reservas son de ejemplo. Todo vive en el navegador: al recargar vuelve a los datos de ejemplo.
